# Задание №3

## Вычисление ленточного определителя трёхдиагональной матрицы

Для выполнения задания необходимо по условиям, указанным для соответствующего варианта:

1. Вывести рекуррентное соотношение для предложенной матрицы.
2. Составить и решить характеристическое уравнение.
3. Вывести формулу общего решения.
4. Рассчитать на основе полученной формулы значение определителя матрицы заданного порядка.
5. Проверить полученную формулу: вычислить определитель третьего порядка непосредственно и по формуле. Результаты должны совпасть.

**Решение должно содержать номер варианта и подробное пошаговое описание.**

Решение необходимо изложить в терминах, обозначениях и приёмах, введённых на лекциях и семинарах. Подмена этой схемы аппаратом, который в курсе не изучался, не принимается — в том числе при верном численном ответе.

Генеративные модели (ИИ) нельзя использовать ни для решения задачи, ни для оформления решения. **Использование ИИ, а также плагиат являются нарушением академических норм и ведут к обнулению оценки.**

Решение задачи нужно оформить в отдельной ветке, в отдельном файле в формате Markdown с названием `ИмяКоманды.md`, который должен быть расположен в каталоге `Задание 3` данного репозитория.

## Информация по Markdown разметке

Полезная информация для оформления решений:

- [Руководство по оформлению Markdown файлов](https://gist.github.com/Jekins/2bf2d0638163f1294637)
- [Система верстки LaTeX, которую можно использовать для математических формул](https://grammarware.net/text/syutkin/MathInLaTeX.pdf)
- [Рисуем диаграммы Mermaid.js в README-файлах GitHub](https://habr.com/ru/articles/652867/)

## Для выполнения задания необходимо

1. Обновить ветку main в локальном репозитории (git pull).
2. От ветки main создать ветвь с названием `ИмяКоманды-task-3`, заменив `ИмяКоманды` на имя команды.
3. В созданной ветке в каталог `Задание 3` добавить файл с решением задачи с названием `ИмяКоманды.md`.
4. Зафиксировать изменения на ветке (git commit).
5. Отправить ветку с изменениями в репозиторий на Github (git push).
6. Создать на Github запрос на слияние (pull request), указав в качестве base ветки `main`, в качестве compare ветки `ИмяКоманды-task-3`.
